# Mate X2 内屏锁定

一个无需 root、无需 Shizuku 的本机控制 APK。为 Mate X2（TET-AN00 / HarmonyOS 4.2.0.182）制作，使用此固件的折叠屏调试接口。

首次使用通过电脑 ADB 授予两项权限。

## 功能

- **锁定内屏**：开启系统显示模式锁定并固定到模式 1。
- **恢复自动切换**：关闭开机自动恢复和系统锁定开关，验证系统已恢复正常折叠策略。
- **开机后自动恢复内屏锁定**：开机后等待系统就绪、屏幕点亮，锁定并确认成功后退出服务。
- **诊断信息**：显示实际应用 UID、服务返回状态及最近操作结果。

自动模式仅在等待和执行锁定时使用前台服务及通知，不主动唤醒屏幕、不在息屏期间循环轮询。确认成功后停止服务、移除通知，并保留下次开机自动恢复的设置。当前锁定由系统维持，应用不再每次亮屏检查或自动补锁；如果其他系统功能解除锁定，重新打开应用可在自动恢复仍开启时重试，也可手动点击“锁定内屏”。

## 安装与首次授权

成品在 `dist/Mate-X2-InnerScreen.apk`，当前应用包名为 `top.xiazr20.innerlock`，版本为 `1.0`（版本代码 `1`）。此包名的新版本仍需按下方步骤实机测试。

2026-10-05 已通过 ADB 在 Mate X2 上卸载旧包、安装此新包。系统确认版本为 `1.0` / code `1`，`DUMP` 和 `WRITE_SECURE_SETTINGS` 均为 `granted=true`，启动新包的 `MainActivity` 返回 `Status: ok`。本次未重启手机；开机恢复和系统启动管理设置仍需按下方步骤确认。

从旧包名 `net.weng.innerlock` 迁移时，Android 会将新包视为另一个应用，不能通过覆盖安装迁移。请卸载旧应用、安装新应用，并为新包首次授权，重新开启开机自动恢复、配置华为“应用启动管理”。旧应用的权限和设置不会自动继承。

以后升级同一包名的应用时，使用同一签名的 APK 覆盖安装，不要先卸载；覆盖安装通常会保留开机恢复设置和已授予的权限，正常使用无需重复授权。

首次安装或卸载后重新安装，在电脑的 ADB 目录运行：

```powershell
.\adb.exe shell pm grant top.xiazr20.innerlock android.permission.DUMP
.\adb.exe shell pm grant top.xiazr20.innerlock android.permission.WRITE_SECURE_SETTINGS
```

连接多部手机时，在 `shell` 前加 `-s 手机序列号`。安装或授权之后打开“内屏锁定”应用。

`DUMP` 用于读取和调用 `fold_screen` 调试入口；`WRITE_SECURE_SETTINGS` 用于写入 `lock_display_mode` 全局开关。两者是系统支持 ADB 授予的 development 权限，正常重启后会保留。应用不声明 INTERNET 权限，不含广告、统计或第三方运行库。

若华为系统询问通知权限，请允许，以便看到等待锁定或恢复失败的状态。部分华为固件会自行加入通知权限管理。

## 自动模式

打开“开机后自动恢复内屏锁定”后，应用会立即尝试锁定，并在以后开机时自动恢复。若系统尚未就绪或屏幕未亮，会等待并进行有限重试；成功后服务退出，通知消失，开关仍保持开启。最终失败也会停止服务，但保留一条可清除的失败通知和开机恢复设置，便于打开应用查看诊断并重试。

关闭开关或使用运行通知中的关闭操作，会禁用下次开机恢复，但不会解除当前锁定；“恢复自动切换”则会同时关闭开机恢复并解除锁定。服务退出后，Android 仍可能暂时缓存应用进程，这不代表服务仍在运行。

如果华为系统拦截自启动，到“设置 → 应用和服务 → 应用启动管理”中，允许本应用自启动、关联启动和后台活动。应用中的设置按钮打开“应用和服务”，需要再点击“应用启动管理”；本机直接打开启动管理页面需要系统专用权限，普通应用无法使用。若无法打开“应用和服务”，按钮会回退到设置首页并提示路径。强行停止应用后，需要手动重新打开，Android 才会恢复向它发送启动广播。

这项功能不会改变折叠屏硬件，也不会改写系统启动镜像。开机动画、恢复模式和服务尚未就绪时，外屏仍可能点亮。卸载应用前若希望恢复自动切换，先在应用中点击对应按钮。

设置页面打开后会依次显示两条长 Toast：“点击‘应用启动管理’，找到‘内屏锁定’”及“关闭‘自动管理’，允许全部启动方式”。提示由系统按顺序显示，不要求应用界面保持打开。应用内按钮带圆角波纹及按下变深反馈；不可用的按钮显示为灰色。

## 新版手工测试

以下步骤用于确认 `top.xiazr20.innerlock` 版本 `1.0` 在本机的实际行为，尚不能视为已通过实机验证。

1. 按“安装与首次授权”安装、授权并完成迁移设置；以后同包名升级可直接覆盖安装。打开应用，确认两项权限均为“已授权”。
2. 开启“开机后自动恢复内屏锁定”，确认显示“内屏已锁定”，等待运行通知消失，再确认开关仍保持开启。
3. 退出应用，连续测试熄屏、亮屏及折叠，观察内屏锁定是否保持、通知是否未重新出现。
4. 重启手机，不手动打开应用。等系统就绪、屏幕点亮，确认自动锁定内屏且运行通知随后消失。
5. 点击应用中的设置按钮，确认进入“应用和服务”，两条操作提示依次出现；按提示进入“应用启动管理”，找到“内屏锁定”并设置手动管理。
6. 关闭开机恢复开关，确认当前内屏仍锁定；点击“恢复自动切换”，确认恢复正常折叠切换且开关保持关闭。
7. 按住“刷新状态”等按钮，确认颜色变深、出现波纹，松开后恢复；重复打开设置时不堆积旧提示。

## 源码与构建

纯 Java / Android 原生界面，最低 Android 8（API 26），目标 API 31。其余设备即使能安装，也不代表支持此华为折叠接口。

Java 包名与应用包名均为 `top.xiazr20.innerlock`，源码位于 `src/top/xiazr20/innerlock/`。

首次准备工具、构建：

```powershell
& 'D:\anaconda3\python.exe' tools/setup_tools.py
& 'D:\anaconda3\python.exe' build.py
```

无需 Android Studio 或 Gradle。工具从官方来源下载到工作区 `tmp/innerlock-build-tools`，不修改全局 PATH。详情见 `tools/README.md`。

本地签名密钥保存在 `.local/`，不会随源码提交。保留它才能构建可以覆盖升级当前安装的 APK。不要分享该目录。
